## 照片墙

页面已加入：
- 无密码照片上传
- 查看照片墙需共享密码
- 可选择“记住密码”
- 自动读取 EXIF GPS 并匹配附近行程地点
- 每张照片显示拍摄地点
- 私有图片 + 临时签名 URL，避免仅靠前端密码造成的绕过

首次启用照片功能还需要创建一个 Supabase 项目并部署仓库中的两个 Edge Functions。步骤见 `PHOTO_WALL_SETUP.md`。
